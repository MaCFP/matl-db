## MaCFP-4 Pyrolysis Model Calibration Exercise Reports
### Summary Reports (Working Group Update: Fall 2026)
The Experimental and Modeling reports contained within this repo are being prepared on behalf of the MaCFP Condensed Phase Working Group. All experimental measurements and modeling results presented here have been submitted voluntarily by participants of the MaCFP-4 Pyrolysis Model Calibration Exercise. These measurements, simulations, and related analysis are presented here for subject matter experts to provide critical review and to ensure the integrity of the results submitted to the MaCFP-4 Condensed Phase Workshop. 

As of Fall, 2026, these reports are still in preparation. The .tex files made available here are intended for review by MaCFP Participants. 
- When completed, final reports (.pdf copies) will be made available on releases page of this Repository: https://github.com/MaCFP/matl-db/releases/tag/v4.0.0
- Highlights of / excerpts from these two documents will also be included in the MaCFP-4 Proceedings document, which will be made available on the Releases page of the macfp-db repository: https://github.com/MaCFP/macfp-db/releases/tag/macfp-4.0


### How to Compile the Preliminary Summary of Experimental Measurements 
#### (Predecisional Draft Report Submitted to the MaCFP-4 Condensed Phase Workshop)
1. Open and Run `Main_analysis.py` [found in: \..\matl-db\Scripts\MaCFP-4]. Each figure (including those in the Supplemental Information Document) will be saved to the [SCRIPT_FIGURES] folder.
2. Compile the file 'MaCFP-4_Experimental_Summary.tex' [found in: \..\matl-db\Documents\MaCFP-4].

Note: Cone and gasification sample areas are currently defined manually in `Cone_analysis.py`. These definitions should be reviewed if sample-area information changes or new institutions are added.
Note: As new data is added to the repo, script figures and tables will update programmatically but the main text (and figure + table captions) will not. The current copy of this report was last compiled on March 30, 2026. As more data is added to this repository, it will be plotted by compiling an update copy of the .tex document. A second version of this document will be revised (edits to the main text and additional analysis) in Summer, 2026 to include final results submitted to the MaCFP-4 Workshop.
